# The shell resolves a literal `trav`, explains unavailable programs and reports a busy mount on recursive removal

A draft, written on 2026-11-25 and checked against `dev` at `27f3d24d`. It is not reviewed. This is the remaining work of [story F4, gate b](../../context/standards/roadmap.md), converted from [the shell pipeline core, §4](../../context/specifications/archive/167-the-shell-pipeline-core/spec.md). It rests on the built shell and verb programs, the pipeline's rule for warnings and the kernel's mount guard.

## The outcome wanted

An agent typing `trav outbound /g/a` gets the same paths, refusal and status as with `traverse outbound /g/a`. A command such as `uv run` answers 127, explains the missing host facility on standard error and leaves a classified warning. An arbitrary typo still gets bash's plain 127. At a mount, including the namespace root, `rm -rf` exits 1 with one `vfs.busy` warning and leaves the files accessible. At an ordinary directory the same command makes one undoable recursive delete.

## What the code does today

Executed through `AsyncVirtualFileSystem.cli` with a named authority on SQLite in memory. With a child mounted at `/mnt`, `rm -rf /` and `rm -rf /mnt` each made one public `delete` as that caller with `cascade=True`, made zero storage deletes, exited 1 and printed `Invalid argument`. The first warning was `vfs.invalid` without a path, the second `vfs.busy` at `/mnt`. Both sentinel files survived. The ordinary control, `rm -rf /ordinary`, made one storage delete, exited 0 and left its child unreadable by path. The mutation path check rejects root before the busy guard (`src/vfs/paths.py:396`, `:870`, `src/vfs/base.py:1852`, `:1905`). The shell maps an unmapped kind to `invalid` (`src/vfs/shell/host.py:501`).

In the same probe `trav --help` exited 127, `traverse --help` printed canonical usage and exited 0. `sweep; posture /; git; curl; nosuch` returned statuses 127, 127, 127, 126, 127 with just the existing `vfs.unsupported` warning for `curl`. The host tables and start path are at `src/vfs/shell/host.py:110` and `:439`. Independently, bash 5.2.37 with an empty program search path exited 127 for bare `trav`. With alias expansion enabled and an explicit alias, bare `trav` ran its expansion and quoted `'trav'` still exited 127.

## The problem

A host-tool refusal looks like a misspelling. A mount refusal can report two different kinds for the same protection, and its text describes neither. Registering a second graph verb would split one permission check and one operation name across callers. At 150,000 verb calls a day a name lookup or a refused delete must never search the ten-million-file namespace.

## Decisions

1. **Resolve the short program spelling in the parsed simple command.** Decided 2026-11-25: the VFS host supplies the single pair `("trav", "traverse")` to the parser. In `parse_simple`, mark the canonical program name only on the first command word whose `as_literal()` is exactly `trav`, after any leading assignments or redirects. Keep its typed word and original byte span for diagnostics, function lookup and deparsing. An argument, assignment value, function definition name, redirection target, quoted or escaped command word, expansion, or path such as `/usr/bin/trav` is unchanged. The rule applies in nested parsed commands, including command substitutions. `command trav` and `command -v trav` take `trav` as an argument. This is the narrow typing convenience of [the verb rename, decision 7](../../context/specifications/archive/2026-11-09-the-verbs-take-the-names-agents-know.md), F4 criterion 7 and choice 1. It is an extension to the VFS program vocabulary for as long as F4 calls for it.

2. **Keep the portable shell and lexical scope intact.** Carry the optional, host-supplied pair through the private binding and start wire into `Config`. Omission selects ordinary parsing on the reference host. Keep the existing `parse(source, limits)` entry unchanged for its callers and add the pair-aware parse entry used by `Machine::new` and by hosts judging that same tree before execution. Share the pair in nested parsers and charge any added command metadata to the tree footprint. After any user alias expansion, a function under the typed name wins as it does today. Otherwise use the canonical program from the tree for normal dispatch, including lookup of a function named `traverse`. A host start for the shorthand is always `Start("traverse", …)`; the host has one `PROGRAMS` entry, one option parser, and the same caller authority. No program or path lookup advertises the shorthand, no operation type or capability changes, and the outer result still has `ops == ("cli",)`. This follows the parser's separation of assignments, redirects and words (`crates/vfs-shell/src/syntax/parser.rs:685`), its distinction between quoted and unquoted text (`syntax/ast.rs:250`) and function precedence (`crates/vfs-shell/src/machine/exec.rs:1083`).

3. **Complete the refusal inventory from a fixed, committed catalogue.** Add the following names to the host's 127 table. Standard error is the existing bash prefix with the typed name and line number, followed by `command not found; `, the suffix below and a newline. Arguments never change the hint. Keep the membership and constant suffixes in `src/vfs/shell/unavailable.py`, imported once by the host. The groups follow the [catalogue's class-f rows](../../context/research/studies/2026-10-15-agent-shell/02-program-catalog.md) at lines 60 and 225–231 and the measured classifier at `context/research/studies/2026-10-15-agent-shell/experiments/s2/matrix.py:77`. These are local diagnostics for programs that cannot run, so no hint promises installation or asks for an external call.

| Names | Exact suffix |
|---|---|
| `uv cargo npm npx pip make gh tokei odbcinst pdftotext vfs` | `host build and package tools are unavailable inside this shell` for `uv cargo npm npx pip make`; `this program needs the host environment` for the other five |
| `docker psql ssh scp sftp ping dig nc host ifconfig ip netstat route` | `this shell has no access to host networking or remote processes` |
| `ps pkill pgrep top nohup systemctl` | `this shell cannot inspect or control host processes` |
| `su chmod chown chgrp mount umount chroot` | `a line runs with its caller's rights; grant and revoke manage access to paths` |
| `uptime nproc sysctl pmset free df open sync tty stty clear reset who users id` | `host system and terminal information is unavailable inside this shell` |
| Remaining unserved names in the committed [Unix-only list](../../context/research/studies/2026-10-15-agent-shell/experiments/s2/classes.md), line 28 | `not a program in this shell` |
| `destroy` and `scrub` | `permanent removal is unavailable inside a shell line` and `storage maintenance is unavailable inside a shell line`, respectively |

The explicit groups take priority over the general suffix. Copy the Unix-only membership into a static set at build time. No installed package or line reads the research files. Recomputing the union of the six classic lists minus the five agent lists reproduced all 692 entries in the committed list, where the catalogue prose says 694. Exclude the existing bash builtin `bind`. The union of the first five rows and that remainder is 734 distinct names. Executed on the dev SQLite host, all 734 as literal commands exited 127 with bare stderr and no fact. Keep the existing hints, the two network 126s, and all running and specified programs, including the standing table's `whoami`, `hostname` and `uname`. Shell syntax and builtins retain their own meanings. `destroy` and `scrub` are named refusal entries only, as required by D57 and the archive's maintenance note at line 244. A subsequently served program leaves the refusal table in the change that serves it.

4. **A known refusal uses the pipeline's bounded warning path.** Adopt 167-5 decision 10 for each added name and for `awk` and `jq` when 168-2 supplies them. 168-2 decision 13, as amended, already follows this rule; keep its exact text and 127. A warning names only the program and its fixed reason. `success` remains true for a completed line. A generic miss and a discovery probe keep no warning. A local function with a catalogue name continues to run. No forbidden program or developer-plane method is invoked. This distinguishes a deliberately unavailable name from a typo using F4's existing kind. In an in-process prototype using the dev host's own `keep`, with `LINE_FACTS=1`, `uv; uv; ps; nosuch` produced four 127s, one `vfs.unrecognized` and one `vfs.budget_exhausted.truncated` rollup counting one, with both occurrences of the `uv` hint on stderr.

5. **Classify deletion of the mounted root in the router.** Every kernel already has a binding at `/` (`src/vfs/base.py:320`). On `delete` only, recognize a valid normalized root as a busy target after argument and closed-kernel checks and before the root-mutation refusal. Apply the same helper to single paths and grouped observations before dispatch. Return `vfs.busy` at `/` with detail `the root mount cannot be deleted`, for either cascade value, with or without child mounts. The result reveals no descendant or mount count. Resolve and validate the path once, retaining mutation checks for every other path. Keep the general rejection of root mutation in `check_mutable_path` and preserve the refusal for reserved or malformed paths. The special case changes classification only and takes no lock. This makes literal F4.6 agree with the router's documented mount protection, including at the root, without a shell-specific guess from an error message. It departs from GNU's separate preserve-root diagnostic because the kernel is the authority on the mount.

6. **Translate busy through the existing host-error wire.** Map `ErrorKind.busy` to the wire tag `busy` in `_HOST_ERROR`, add `HostError::Busy` to the shell and round-trip it through both binding and WebAssembly codecs. Its C-locale rendering is `Device or resource busy`, verified with `strerror(EBUSY)`. The shell's ordinary `rm` then prints `rm: cannot remove '/': Device or resource busy\n` for the root. The original router fact supplies the warning and path. The same rule covers a named mount and an ancestor containing one. No new delete strategy, traversal or force exception is required (`crates/vfs-shell/src/programs/files.rs:741`, `:810`, `src/vfs/shell/host.py:486`).

## Cost

Let C be the number of parsed simple commands, bounded by the declared `tokens` and `source_bytes` limits (`crates/vfs-shell/src/syntax/mod.rs:18`). Each head needs at most one fixed-length spelling comparison. The optional marker costs at most C fixed-size fields and a shared canonical spelling, included in `Script.footprint` against `memory_bytes` (`crates/vfs-shell/src/machine/mod.rs:377`). Skipped branches require no host start. Each executed external miss takes one existing start, hashing the bounded command name once and an expected constant number of table probes. The table size is fixed per process by its committed names, with shared suffix strings. Repetition costs one write of bounded text per rejection against `output_bytes` and at most `LINE_FACTS` held facts plus the existing rollup (`src/vfs/shell/host.py:122`, `:335`). The root classification is a comparison on an already normalized path, independent of mounts and files. At 150,000 single-command calls this work adds zero SQL statements, row visits, bind parameters or locks, on SQLite, Postgres and the generic dialect floor. Successful traversal and the ordinary cascading delete retain their existing costs.

## Choices to confirm

1. **Keep the short spelling under the acts-as-bash ruling?** Take the additive F4 spelling for a bare literal command head in the VFS host only, with an existing function retaining precedence. The alternative leaves bare `trav` unresolved and requires an explicit bash alias or function. A parsed command can lose this one optional rule before the freeze without changing a stored operation, capability or tool name.
2. **Which fact accompanies the two D22 hints?** Take the additive bounded warning from 167-5 decision 10 for `awk` and `jq`, retaining 168-2's exit and text. Its decision 13 follows the table. One table-wide rule lets an agent distinguish a catalogued unavailable command from a typing error.

## One line

A literal `trav` uses the canonical traversal program, catalogue misses explain their refusal, and recursive removal of a mount reports `vfs.busy` while preserving its contents.
