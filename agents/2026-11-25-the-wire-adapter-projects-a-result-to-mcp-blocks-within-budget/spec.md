# The wire adapter projects a result to MCP blocks within budget

A draft, written on 2026-11-25. It is not reviewed, and nothing is built. Checked against `dev` at `27f3d24d` for [roadmap story M1](../../context/standards/roadmap.md), gate b, unit 171-1. It converts §§1.1–1.3, 2 and the in-process checks of §5 of [the archived MCP adapter specification](../../context/specifications/archive/171-the-mcp-adapter-and-the-cli-tool/spec.md). It rests on the result envelope, the shell result, listing pages, the renderer, row vids and the replay and argument tables.

## The outcome wanted

A client reading a file gets one readable text block. A requested PNG can also arrive as an image. A file that cannot fit inline can arrive as a resource link. A client consuming only the structured answer sees precisely the displayed observations, their fetched-field masks and their version identifiers. Either client can tell where a listing stopped. A caller repeating a mutation can discover its replay behaviour in the tool description. A host importing a tool reply recovers native VFS evidence or receives ordinary rows for a foreign tool's content.

## What the code does today

Executed on in-memory SQLite and a disposable Postgres database through `AsyncVirtualFileSystem`: write `/p.bin` with bytes `fb ff`, `/z.bin` with empty bytes and `/a.txt` with text. A read of `/p.bin` with only `data` requested populated `data, kind, path, version` and had no MIME type. Adding `source, mime_type, size_bytes` returned `application/octet-stream`. The payload spelled the bytes `-_8=`; strict standard base64 for those bytes is `+/8=`. On both engines `ls("/", limit=1)` showed `/a.txt` and printed `more: after=/a.txt`. An anonymous `cli("false")` succeeded with `exit_code=1`, `statuses=[[1]]` and all five shell fields in its payload.

Executed in process: 10,000 image observations at `/00000.png` through `/09999.png` in an `ls` result produced 109,999 characters and 10,000 payload rows. For 10,000 errors of one kind, `to_payload(max_errors=100)` emitted two entries. For 10,000 distinct peer kinds it emitted 10,000. The threshold triggers grouping by kind, severity and retryability and can retain a source per discarded error (`src/vfs/results/envelope.py:835`). A native envelope with one valid URL-safe body, one invalid path and a peer claim of failure recovered the original bytes and produced one quarantine warning and one fatal claim. Two valid observations at `/x` with versions 1 and 2 both rendered `/x`. An observation's `source` accepts only `text`, `bytes` or null (`src/vfs/models/entry.py:455`); it cannot carry a resource URI.

## The problem

The in-process representation can hold an entire batch. Serializing it before selecting rows base64-encodes bodies that the client cannot display. A separately clipped string gives no way to distinguish two observations at the same path, a traversal line representing an edge and a node, or a batch total that names no individual row. At the reference deployment's 150,000 calls a day and 10,000-file batches, a transport that sends either the full payload or a misleading prefix makes a bounded text renderer ineffective.

## Decisions

### 1. The adapter has two pure entry points and no transport dependency

`vfs.mcp.adapter.to_call_tool_result(result, *, revision, projection=None, pageable=False, budgets=DEFAULT_BUDGETS)` returns an MCP `CallToolResult`. `from_call_tool_result(result, *, at, budgets=DEFAULT_BUDGETS)` accepts a decoded result object or its JSON mapping and returns a `Result`. Accepting a mapping on ingress preserves block types unknown to the installed union. Neither entry point fetches a body, follows a URI, runs a tool, opens storage or mutates its input. Apply the outgoing projection only on the last hop. Preserve `isError = not result.success`, including a successful shell result with nonzero status. Leave the revision-specific `resultType` to SDK serialization. Precedent: archived §2.1 and the derived verdict at `src/vfs/results/envelope.py:388`.

### 2. One set of eligible verbs and one input projector describe the tool surface

In `src/vfs/ops.py` derive `AGENT_OPS = ALL_OPS - DEVELOPER_OPS`. Eligible and implemented are different checks: serving takes the intersection with `fs.capabilities()`, then adds the separate `cli` front. Executed on SQLite and Postgres: 25 ops minus four developer ops gave 21 eligible names; the default storage supplied 20, omitting `run`. That yields 21 tools with `cli`. The generic profile additionally withholds `search` (`src/vfs/storage/backends/database/backend.py:228`), giving 20 on that floor; `tools={"cli"}` gives one. A storage that supplies `run` may change the count. Never invent a tool for an unavailable capability.

`input_schema(op)` in `vfs.mcp.schemas` reads `PARAMS[op]` in declaration order. A top-level object rejects extra keys. Mirror each row's requiredness, non-null domain, bounds, choices, doc and JSON-representable default. Optional nullable values admit JSON null; required values never do, matching `src/vfs/params.py:596`. A missing key stays missing. Withhold `authority`, `observations` and `provenance` by name in `WITHHELD`. The wire never accepts a nested entry owner or provenance. For `run.arguments` the nested object is the target tool's own data and is passed as a single argument. Use the actual `PARAMS` row when a future op or argument lands. Today `run` takes `path, arguments, authority` there (`src/vfs/params.py:390`).

| Parameter kind after the named dependencies | Wire value and conversion |
|---|---|
| `path`, `str`, `int`, `bool`, `dict` | JSON string, string, integer, boolean, object respectively. Enforce declared choices and range. Reject booleans for integers and other coercions. |
| `str_seq`, `str_set` | Arrays of strings. Sets require unique items. For `columns` use the sorted `OBSERVATION_FIELDS` enum, including `vid` after its landing (`src/vfs/results/projection.py:28`). Display-only names are outside this enum. |
| `bytes`, `entries` | Standard padded RFC 4648 base64 for bytes. Entries are a closed array item with `path` and exactly one of text `content` and base64 `data`, including empty bodies. Decode to `Entry` values. |
| `pairs`, `edges`, `edits` | Closed array items become `TwoPathOperation(src,dest)`, `Edge(source,target,edge_type,weight?)`, and `EditOperation(old,new,replace_all?)`. Paths and text are strings, weight a finite number, the edit flag a boolean. The narrower edge form is archived §1.1's wire allowlist (`src/vfs/models/edge.py:34`). |
| `vid`, `vids`, `token` | A vid or the literal `"absent"`; for a map each string path has that same value domain. Use the vid validator of its owning module. Derive token length and printable ASCII domain from the shared request-key contract. |
| `authority`, `observations`; named `provenance` | No schema property or caller argument. |

`call_args(op, arguments)` uses the same projection to validate names and JSON shapes before constructing the Python values. Use strict standard base64 decoding with validation; refuse non-ASCII, malformed padding and the URL-safe alphabet. On any invalid argument or failed item constructor return an ordinary failed `Result` for the op with `vfs.invalid`, dispatch count zero and a bounded message naming the argument, without echoing its contents. On success return a kwargs dictionary. Leave cross-argument `RULES` and `VALUE_RULES` to the existing router gate. The serving front supplies authority and stamps `mkedge` provenance from the actor. When `data` is requested its fetch projection adds `path, kind, source, mime_type, size_bytes, version, vid`, but the display projection remains what the caller requested. This explains which layer can supply a missing MIME type.

### 3. The annotations and replay sentence come from kernel facts

Decided 2026-11-15: D7 removes `overwrite`, and D11 withholds `idempotentHint` whenever any form can apply twice ([kernel rulings](../../context/specifications/active/2026-11-15-the-kernels-public-names-and-argument-families-are-ruled.md), decisions 7 and 10). Keep `append` on `write`. In `schemas.py`, one `TOOL_DESCRIPTIONS` entry per eligible verb gives its purpose in one or two sentences. Append one generated line for each `REPLAY` member, listing the default and exceptional forms in table order and the status, kind/severity or repeat effect recorded in each `ReplayAnswer`. No mutation description makes a keyless resend guarantee that only a keyed call can give.

`readOnlyHint = op in READ_OPS or op == "grants"`. Declare one `DESTRUCTIVE_OPS` set beside the op classes for the archive's `delete, move, write, edit, revoke`; emit `destructiveHint` by membership. `idempotentHint` is present and true only for `IDEMPOTENT_OPS`; omit it elsewhere, even when this call supplies a key. `cli` takes no replay, read-only or destructive promise. It and the description of a shell line belong to the front. A new op confronts the description and hint tests when its kernel facts land.

### 4. The wire renderer identifies complete observations by input index

Extend the cut of 167-3 in `src/vfs/results/cut.py` and the arrangement builders in `src/vfs/results/render.py`. Each block records which input indices it finishes and, for a grant or membership entry, its extra name and index. Keep existing row counts and listing paths for their present callers. Expose `render_wire_result` in the render layer to return the text, retained indices, displayed extra entries, stream slices for a line, and safe continuation. It imports no MCP type. Pass the caller's projection through existing validation and arrangement selection. Render once. A count, a prefix of the input and a path set each lose information for at least one arrangement.

A whole displayed observation has an identifying detail block. A table row, a read block, a search hit and a group of grep lines each finish their own index. Tree ancestors without a row finish none. A traversal child can finish its node and the actual incoming edge; duplicate paths retain their separate indices. A named single action or single-file write detail finishes its row. A batch count, table header, projection note, grant entry, line of shell output or error finishes no observation. For a batch summary retain the summary and count individually unshown observations as elided. On the wire take whole observation blocks: omit a partial multiline observation from both channels. Empty content with an identifiable read row gets a bounded path header on the wire. A row without any drawn detail is unshown, even on an uncut aggregate result. Preserve input order in the structured list and media order, independent of drawing order. These rules extend decisions 5 and 11 of 167-3 only where exact correspondence is required.

### 5. Budget the text, its evidence and its cursor together

Use an immutable `WireBudgets` with named maxima: text `RENDER_CHARACTER_BUDGET` (32,768 Unicode characters including marker, separators and facts), `MEDIA_BLOCK_BUDGET = 8`, `MEDIA_BLOCK_BYTE_BUDGET = 1 << 20`, `MEDIA_BYTE_BUDGET = 4 << 20`, `LINK_BUDGET = 64` and `PAYLOAD_ERROR_BUDGET = 100`. Default values follow archived §2.2 and M1 criterion 2. Accept lower host settings only. Require positive integers for text and error-head limits, nonnegative integers for media and links; reject booleans and over-ceiling values at construction. A zero media or link budget disables that channel. Choice 3 gives the last-resort cut when errors alone exceed the text cap.

Whenever the native facts fit, preserve their text and grouping, severity order and line breaks. At the normal renderer entry point as well as on the wire, a failed result leads with the errors section so the first cause precedes any successes. Success keeps its warnings and info after the body. Reserve space for facts, a marker and a safe paging line before admitting observation blocks. Use 167-3's marker grammar, narrowing hint and character counts. Exactly one outgoing projection warning, `vfs.budget_exhausted.truncated` at warning severity, describes omitted observations under `data["vfs.elided"] = {"rows": N, "first": "<path>"}` and puts the same hint in its message. The first path is the first omitted input index, already visible to this caller. Combine other wire elisions into this record with distinct counters. Omit `first` when no observation was elided. Omit the projection warning entirely when nothing was elided. Never add a second copy of the marker for this warning. Preserve prior kernel facts of the same kind. A line that does not parse carries its place in the fact's `data` (`line`, `column`, `offset`, `expected`, `incomplete`, `text`, `caret`, unit 167-4); the wire's text draws no caret, so a caller on a revision without `structuredContent` gets bash's line number alone.

For `ls, tree, glob`, the outgoing payload's `next_after` agrees with the line printed. An intact page keeps the kernel key. An existing result key proves that a call can page. For a path-addressed listing that accepts a cursor, the handler also passes `pageable=True` from its arguments so even a cut final page can resume. A cut with either proof uses the largest contiguous shown frontier of 167-3 decision 13, even when the last drawing order differs. With no such frontier omit the key and give the narrower-scope hint. With neither proof, use the narrowing hint alone. The observations and op name cannot distinguish an unordered in-hand listing from a resumable call. Never advance the source result. `read` can suggest the `cli` form `sed -n 'A,Bp' <path>` for text until bounded reads land; bytes can be requested explicitly by path. `cli` names `head`, `tail` or `sed -n`. Do not advertise a `range` argument until it is in `PARAMS`.

### 6. Bound unusual evidence before serializing the structured answer

Project a copy of the actual subclass on the selected observations and grant/member entries; call its byte-stripping `to_payload(include_bytes=False, max_errors=PAYLOAD_ERROR_BUDGET)` on the bounded set of heads. Do not dump the full result first. Preserve each displayed row's fields, including `vid`, and every populated name except `data`. Never recreate a missing field or mint a vid. Preserve `success`, `ops`, and error severity. Keep safe JSON extras, including known typed extras, within the declared budgets. Remove bytes, byte buffers and raw media-bearing protocol blocks from open error data and extras before the JSON serializer can encode them; retain the enclosing object's other JSON fields, omitting a binary-valued property or replacing a binary array element with null. Ordinary caller text is opaque. The byte-free guarantee concerns transported bodies, including embedded blobs under a raw-block extra.

The runtime's rollup threshold is not a hard entry limit. When it fires, take heads in stable fatal, warning, info order and bucket repeated facts by the native key `(kind, severity, retryable)`, retaining at most the head budget of distinct keys. Reserve summaries by severity for excess groups. Append one compact `vfs.rollup` count for each retained group with a tail and at most three excess-group summaries; no unbounded source list. Count each input fact exactly once. Give an excess summary fatal severity if it represents failures, warning for warnings and info for info. Count summaries outside the head budget and append the one optional projection warning last. The wire has one fold of its facts, and both channels carry it. The text block's errors section is drawn by 167-3's renderer from the same bounded error list the structured `errors` carries, handed to `render_wire_result` as decision 24 of 167-3 hands `render_result` a rolled copy; the wire never groups facts a second way for text. Its grouping is the envelope's `_rolled_errors` key, which `to_payload(max_errors=...)` and `to_str(max_errors=...)` share, read at `max_errors=PAYLOAD_ERROR_BUDGET`, and 167-3 decision 19's merge of equal records then applies to the drawn lines. So whenever the result holds at most `PAYLOAD_ERROR_BUDGET` distinct `(kind, severity, retryable)` keys, the wire text's errors section equals the errors section of `Result.to_str(max_errors=PAYLOAD_ERROR_BUDGET)` on the selected copy, line for line. The wire goes past 167-3's rollup in two steps only, each for a reason 167-3 leaves open by design. First, past `PAYLOAD_ERROR_BUDGET` distinct keys the excess groups become the at most three severity summaries above, appended to that one list: `_rolled_errors` keeps one head per key, so 10,000 distinct peer kinds give 10,000 heads (167-3 decision 24 names this case as the wire's own), and the wire, unlike `to_str`, owes a bound on what it sends. Second, the text block owes a hard character ceiling that 167-3 refuses its errors section (its decision 7, F1 criterion 3): when the drawn lines of that bounded list alone exceed the text allowance, show its complete lines in fatal, warning, info order and reserve one compact line with the counts of omitted lines by severity. That cut removes lines of the one list and regroups nothing, so the structured `errors` still names every group the text omits. Both are pinned: 167-3's `tests/results/test_render.py::TestRenderBudget::test_max_errors_rolls_ten_thousand_warnings_and_the_budget_alone_keeps_them` pins the text fold, and this unit's `test_errors_fit_and_keep_the_verdict` pins its equality on the wire and the two steps past it. For an oversized first fatal line retain its severity and a character-limited first cause, visibly clipped. Under a host text limit shorter than the normal marker use a clipped marker ending in `…`; the structured evidence retains the counts. This separates display loss from success and bounds even hostile error kinds.

Use `PAYLOAD_BYTE_BUDGET = 4 << 20` for the compact UTF-8 JSON (no ASCII escaping, no separator spaces) of `structuredContent` (choice 4). Reserve the mandatory envelope, bounded facts, elision record, safe cursor and scalar line status before admitting optional data. Account for JSON escaping and separators. Fit both the rendered block and its byte-free row before accepting either. Stop at the first block that exceeds the remaining allowance; an oversized scalar in an observation therefore omits the whole observation and names it in the warning. For oversized evidence keep the kind and severity where they fit and bounded detail or an explicit severity summary otherwise. For open extras omit overflowing members in sorted-key order, recording a count. Keep `stdout` and `stderr` as the prefixes actually displayed, cut at a whole-line boundary in the concatenated stream then split at the original seam. Preserve `exit_code, fuel_used`, and all complete pipeline arrays of `statuses` that fit, with the omitted pipeline count in the warning. All five fields remain present, including zero and empty values. Apply the same count rule to clipped grants and members. Host byte limits must fit the compact minimum envelope, including the full continuation/elision metadata for a maximum-length path, or construction raises `ValueError`. Charge typed-block/link metadata at its escaped UTF-8 JSON length against an independent allowance equal to `PAYLOAD_BYTE_BUDGET`, excluding the separately charged media body. When the metadata does not fit, keep the text and row alone. The two four-MiB allowances, the encoded media ceiling and one text block leave headroom under the archive's 16-MiB transport ceiling.

### 7. Walk the shown observations once for media and links

One `TextContent` comes first, even if the body was empty. Then emit eligible blocks in observation order. Test the mask as well as the non-null value of `data`, `mime_type`, `version`, `updated_at` and `size_bytes`. Empty bytes are fetched bytes. Measure the actual `len(row.data)` before encoding. Case-fold the base MIME type before its parameters for classification, retain its declared value on the wire and never sniff a body. Use `base64.b64encode` on the original bytes. Each accepted block must fit the remaining count, its individual raw-byte limit and the total raw-byte limit. A miss costs no inline allocation and a later smaller row can still inline.

| Displayed evidence | Text | Following MCP block |
|---|---|---|
| Text file or text program output | Existing arrangement or verbatim read | None |
| Bytes without fetched data, or without fetched MIME | Shared binary placeholder in a body/data arrangement, with unknown parts marked `?` | None |
| Fetched PNG, JPEG, GIF, WebP, or `audio/*` | Binary placeholder | `ImageContent` or `AudioContent` if admitted, else a link if eligible |
| SVG or `text/*` stored as bytes | Placeholder and its fetched rendering per 167-2 decision 8 | None; no decoding or link |
| Other fetched binary file, including unsupported image formats | Placeholder | `ResourceLink` while a link remains |
| Directory, edge, traversal node, trash or version evidence | Its arranged row | None |
| Binary program output | Placeholder | May inline eligible media. Until T2 serves the run record, omit any fallback link for `/.vfs/run/` |
| Grants, members, stdout, stderr and exit status | Table or shell output; exit/status evidence remains structured | None, except for an explicitly supplied terminal file observation |
| Failure, warning or info | Decision 5's facts section | None |

For a path-only listing the path is already the text for its row. If an older revision cannot carry the audio or link and this arrangement would leave no placeholder, include the shared placeholder with that row before the cut. For a shell terminal file observation supplied by 171-3, render its identifiable placeholder once with its row index in place of the terminal binary display; never infer a file by scanning shell output. The `cli` front owns selecting and fetching that observation. `LineResult` with plain stdout/stderr requires no synthetic row.

Set `_meta["dev.vfs/path"]` to the public path and `dev.vfs/version` only when fetched and non-null. If several retained observations share a path, also include `dev.vfs/row`, the zero-based index in the structured observations, to make reattachment unambiguous. Links use the basename as `name`, the shared placeholder as `description`, populated MIME and size, and populated `updated_at` as `annotations.lastModified` in ISO format. A link does not count against the media budgets. Once the link limit is spent the row remains visible in both other channels.

### 8. One URI codec and a revision check keep old clients readable

In `src/vfs/mcp/uri.py`, `vfs_uri(path)` prefixes `vfs://` to the absolute path percent-encoded as UTF-8 with slashes kept. `path_from_vfs_uri(uri)` requires that scheme, empty authority and absolute path, rejects query and fragment delimiters, malformed escapes and invalid UTF-8, decodes once and applies the kernel `Path` gate (`src/vfs/paths.py:175`). The codec raises `ValueError` on malformed input; the resource handler owns its RPC error. No file URI or ambient filesystem access is involved.

For negotiated revisions from 2025-06-18 on, emit `structuredContent` and the typed blocks above. For 2024-11-05 and 2025-03-26 emit only the first text and supported image blocks; suppress audio, links and the structured field. Use the negotiated revision supplied by the front. Decided 2026-10-15: degrade on legacy revisions rather than refusing a call. Vendor the three test schemas for 2025-06-18, 2025-11-25 and 2026-07-28 from the revisions identified in [the block study](../../context/research/studies/2026-10-15-agent-shell/08-mcp-content-blocks.md), with their upstream licence. Keep validation local.

### 9. Output schemas describe the wire envelope, including shell and row fields

Declare `ResultPayload` in `vfs.mcp.schemas` with required boolean `success`, array of strings `ops`, array of observations `observations`, and array of `ResultError` objects `errors`. `next_after` is an optional path. Require the observation's path, derive its property vocabulary from `Observation`, keep `vid` optional, allow only null/absent `data` and exclude `data` from a wire `populated` array. The model permits additional top-level JSON properties. Known optional fields include `grants` and `members` as arrays of objects using the grant/member columns at `src/vfs/results/render.py:592`, `stdout, stderr` as strings, `exit_code, fuel_used` as integers and `statuses` as an array of integer arrays. Do not advertise the archive's `set_e_tripped` as a shell field. Generate `outputSchema` from this model and validate successes and failures alike. All four required keys appear even when their arrays are empty.

### 10. The native inverse restores bytes only to the row the peer identified

Treat a mapping bearing `ops, observations, errors` as a VFS payload. Call `Result.from_payload` with the peer's structured fields and the claim `success = not isError`. Fatal facts still win over a claimed success. An unsupported claim of failure becomes the existing fatal `vfs.internal` with `vfs.claim`. Preserve the shell fields as extras on the returned `Result`. For a valid image or audio block, strict-decode standard base64 and copy the row with `data` and `"data"` in its mask. Match canonical path, the optional version and the optional structured-row index. Require a unique surviving row and check its populated MIME for compatibility. Track the original wire position across quarantines. Never restore bytes to the next valid row after a bad row, to every row sharing a path, or by block order alone.

Admit incoming media using the same individual, count and total raw budgets; check encoded length including padding before allocating. For a VFS payload carrying old embedded row `data`, bound its encoded size before handing its URL-safe representation to the native decoder, and charge accepted row bytes against those same limits once. Prefer a matching already populated body, treating a disagreeing block as malformed. Invalid encoding, conflicting metadata, duplicates or an unmatched attachment produce one `vfs.internal` warning each, naming block index and reason and retaining the valid siblings. Excess bytes produce the truncation warning and metadata-only row. Do not put raw base64 into error data. Ignore the native display text/links for row reconstruction. Unknown blocks still follow decision 11. Nothing rehydrates a link.

### 11. Foreign blocks use the indexed rows of their consuming contract

T4 criterion 1 on `dev` (`context/standards/roadmap.md:816`) and [the catalogue's inbound table](../../context/specifications/archive/170-tools-and-mcp-servers-as-views/spec.md) §4 assign each content block its zero-based wire index. Use `at.joinpath(str(i))` and the native `Path` gate. Preserve order and do not use a peer-supplied path or filename as an address in this branch. This supersedes archived 171 §2.6's joined stdout, extension-derived filenames and URI in `source`. A caller receives one result without an implicit read or tool invocation.

| Block | Observation and envelope extras |
|---|---|
| `text` | `content=text`, `source="text"`, `mime_type="text/plain"` |
| `image`, `audio` | Fetched `data`, `source="bytes"` and the declared MIME, subject to decision 10 |
| Embedded `resource` | Text or strict-decoded blob at the block index, with supplied MIME. Preserve the embedded URI in the indexed `links` extra. |
| `resource_link` | Text row with the one-line `[link <uri> <mime> <size>B -- <name>]` display, skipping absent fields. Preserve the block in `links` keyed by decimal index. |
| Unknown | Text row `[unknown block <type>]`, with line breaks collapsed in the type. Keep the raw JSON block in the `vfs.blocks` extra by decimal index. It remains available to the importer. Decision 6 excludes binary carriers from subsequent projections. |

Retain non-native `structuredContent` in the extra `structured`. With empty content and a structured value, emit one `application/json` text row at `at/0` containing its compact JSON. For a foreign `isError: true` return no observations, keep `structured`, join its text blocks in wire order with newlines in `stderr`, and set `exit_code=1`; the flag alone mints no kind. A transport or RPC error is outside this function. Malformed known blocks and overlong synthetic paths quarantine individually with a bounded reason; retain other blocks and foreign fields. Keep path, version, vid and original row masks in the native branch only. These two interpretations of `isError` distinguish a peer claiming a failed VFS result from an external program returning an unsuccessful status.

## Cost

At 150,000 calls a day and roughly 20 arriving per second at peak (`AGENTS.md:68`), the projection adds zero statements, binds, locks and body fetches per call on SQLite, Postgres and the generic floor. It reads the caller's admitted result. The renderer prerequisite already visits every row and draws its arrangement to count removed characters. Retaining source indices adds O(R) labels for R input observations. The rendering and error scan therefore cost the input rows, rendered characters and input errors, including 10,000 for a full batch, not the ten-million-entry corpus. Use the existing ordered blocks, maintain retained indices and counters in one pass, and avoid repeated serialization or re-rendering of successively shorter prefixes. Reserve fixed metadata space up front and release the unused part when finalizing the cut. One 10,000-row batch costs at most 10,000 row classifications; 100 such nightly batches cost at most one million. Schema generation is per eligible tool at registration and has no per-file multiplier.

At most eight base64 encodes visit at most four MiB raw per call. Separate padding costs at most eight groups of four output characters beyond four thirds of the raw bytes. At most 64 URI encodes visit paths of at most `MAX_PATH_LENGTH` UTF-8 bytes (`src/vfs/paths.py:41`). Only shown wire rows enter payload serialization. For the inverse, count decoded media against the same four-MiB allowance. In mapping mode, consume foreign blocks once in wire order and stop materializing rows when their body-free compact JSON, links and raw extras fill the structured-byte allowance. Record the omitted block count once, retaining the foreign exit status. A pre-decoded input mapping itself is already resident and is outside this result-allocation bound. Account compact JSON incrementally against the declared byte allowance, stopping before building a giant encoded field. Error grouping uses at most the head budget of groups and three excess counters. Input storage and F1's rendered body can exceed the output budgets. This work adds no global lock, persistent record or work to index visits.

An independent Python oracle on the 10,000 numbered image rows, using the ordinary path list, reserving its row marker and narrowing hint at 32,768 characters, kept 2,969 rows in 32,760 characters, elided 7,031, and admitted eight two-byte images and 64 links. With raw lengths `[M+1, M, M, M, M-3, 4, 3]`, where M is one MiB, it admitted five media blocks totalling exactly four MiB and linked the first and sixth. The URI oracle round-tripped `/a b/#?%/é` through `vfs:///a%20b/%23%3F%25/%C3%A9`. These are executed oracles for the accounting and encoding, not an adapter on `dev`.
