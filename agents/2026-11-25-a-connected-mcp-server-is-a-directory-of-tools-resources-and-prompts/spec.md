# A connected MCP server is a directory of tools, resources and prompts

A draft, written on 2026-11-25. It is not reviewed, and nothing of the MCP client view is built. Checked against `dev` at `27f3d24d`, it serves [story T4](../../context/standards/roadmap.md), gate b, and converts [spec 170 §§3–4 and 7](../../context/specifications/archive/170-tools-and-mcp-servers-as-views/spec.md). It rests on the catalogue's rights, the public tool call, the inbound wire adapter and the root binding's run store. The job contract governs a server's request for input when that contract lands.

## The outcome wanted

After the host connects a server named `maps`, a caller can list `/.vfs/mcp/maps`, read a tool's manual, run the tool by its full path, read a listed resource and inspect a prompt's arguments. Only running the tool sends `tools/call`. A named caller receiving five foreign blocks can reopen the five numbered files of its completed call. A tool's own failure prints its text on stderr. Losing the connection gives a classified failure even if the outcome at the server is unknown. The next call can open a new connection without repeating the lost call.

Executed with Python 3.13.5 in the checkout, importing `vfs` succeeded and the module finder found no `mcp`.

Executed the real router and storage on disposable Postgres. With `set_posture("/.vfs/mcp/sample", "list")`, two named callers held list and neither held read on the unstored `tools/echo` leaf. The SDK's upstream default branch was resolved on 2026-11-25 to [python-sdk main at 77001c96, MIT](https://github.com/modelcontextprotocol/python-sdk/tree/77001c96f9507be0f4d009b83210a384a5e08bda). ## The problem

A manifest is safe to inspect only if reading it cannot execute its tool. A resource size, an error or a completion link can also disclose a target to a caller who cannot read it. At 150,000 calls per day, re-listing each server for every lookup turns repeated local reads into network traffic. Retrying a call after a lost reply can repeat an external effect. Closing a borrowed client from the router's disposal task can leave a child or connection alive.

## Decisions

1. **Study before implementation.** First, spike one connection owner for real stdio and streamable HTTP on Python 3.11 and 3.13. Count entries, exits, live children, cancelled requests, a second request on the same client and one replacement after a kill. Include single-send header mismatch, mixed known/unknown blocks and rejected output schema so the raw reply boundary is proved. Second, census three or four real catalogues including the reference filesystem server, the GitHub server and a TypeScript/Zod server. Count tools, properties per binder rule and whole-object JSON fallbacks. Third, negotiate with a 2025-06-18 stdio server and a session-id HTTP server. Record discovery, fallback, absent TTL, expired session and call counts. Record SDK revision, license, server versions and fixture hashes. These are the three first tasks from archived lines 5–8. The census may justify a later syntax proposal. It does not add dotted flags here.

2. **Connect eagerly on the host administration face.** Add `add_mcp(name, server, *, list_floor_ms=None, credentials=None) -> None` and `remove_mcp(name) -> None` to the async router and its synchronous facade only. Accept a streamable HTTP URL or SDK stdio parameters. For a static HTTP bearer accept a nonempty secret string containing one token without whitespace or controls, keep it in the configured transport, send only to the configured origin, and refuse URL userinfo, credential-bearing redirects and an unencrypted non-loopback credentialed endpoint. Use no inbound token or environment lookup. Reject credentials or a nonempty explicit environment on stdio before spawning. Resolve the executable at registration and spawn with an explicit clean environment (only platform-required nonsecret startup values); passing an empty SDK `env` still inherits variables. Supply credential-free argv as host configuration. Error details, repr, logging, run metadata and discovery never serialize transport configuration. D16's host resolver and per-principal pool are I4's addition. Static servers have one authenticated upstream identity across locally authorized callers.

Use the host's validated single segment as the server address. Validate through `src/vfs/paths.py:604`, require spelling unchanged by path normalization and a full path within `MAX_PATH_LENGTH`. Reserve the name under the topology lock before any I/O. Duplicate name, invalid configuration or absent name on remove raises `ValueError`; a closed router refuses through its existing closed gate. Failed connect or initial discovery raises a redacted host exception carrying the classified connection failure, releases the reservation and joins the owner. An unavailable optional dependency raises `ImportError` naming `pip install 'vfs-py[mcp]'` before starting a task. Declare `mcp>=2.3,<3` in the shared optional extra and in development dependencies, lock and test the selected wheel after the spike. Keep SDK imports at the top of `vfs/mcp/client.py`, loaded at the admin boundary using the optional-module pattern at `src/vfs/rendering/seam.py:397`. Its declared dependencies supply the stronger Pydantic floor on the four matrix Pythons (`python-sdk/pyproject.toml:129–149`).

3. **One task owns the entire lifetime of one connection.** Only that supervisor enters and exits the negotiated client and its task group. Publish the view once discovery succeeds. Dispatch admitted request workers concurrently within its lifetime, correlated by connection generation and request id. Bound both open/reserved servers (`MCP_SERVER_LIMIT=64` per router) and pending plus running requests (`MCP_IN_FLIGHT=16` per connection). Refuse excess registration before spawn and excess calls with `vfs.busy`, exit 1, before send. A cancelled waiter cancels its worker and discards any late reply. A broken generation settles all its unanswered requests, closes once and leaves the name disconnected. On the next admitted operation, concurrent waiters share one reconnect/rediscovery. A failed attempt advances the next eligible instant by doubling from `MCP_RECONNECT_INITIAL_MS=250` to `MCP_RECONNECT_BACKOFF_MS=30000`; before then report unavailable. There is no background retry loop. Reset on a complete reconnect. Never send a request to an obsolete generation.

Remove and close first withdraw the name, stop new work and signal its owner outside the lock. Settle or cancel workers, close/reap the transport, join the owner and release retained credentials. Closing during registration invalidates the reservation so a late connect cannot publish. Keep unfinished shutdowns reachable across cancelled or timed-out closes, as for owned storages. A second close joins the same disposal. No network await, SDK exit, job wait or database operation holds the topology lock.

4. **Publish complete immutable catalogue snapshots.** At connect discover the capabilities and page each advertised list: tools, resources, resource templates and prompts. A missing capability means an empty directory. In one snapshot, list order fixes concrete resources' zero-based ordinals and templates follow them. Page each method to a null cursor, refusing repeated cursors, duplicate canonical names within a directory, invalid segments or incomplete pages. Set `MCP_LIST_PAGE_BUDGET=64` per method, and bound aggregate schema/manual/identifier bytes across registrations by 170-2's `TOOL_CATALOGUE_BYTES`, including staged replacements. Reject a schema over the shared `SCHEMA_BYTES` without trimming it. Admit or reject the snapshot as a whole, including cross-server capacity reservations. A failed refresh surfaces its classified failure, publishes nothing and admits no call from a known-stale list. Retain the last good image for existing readers only. Retire its buffers when their bounded requests end.

Use one refresh in flight per server, and at most one attempt per server per shell line (per operation outside a line). Use a monotonic injected clock. Earliest normal refresh is last successful fetch plus the greater of the minimum of the pages' effective list TTLs and `MCP_LIST_FLOOR_MS=30000`. Absent TTL counts as zero. Use the SDK's maximum TTL clamp and keep cache scope within the connection. `list_floor_ms=None` uses the default and a nonnegative integer overrides it, including zero. A failed attempt is also subject to the floor before another line tries. No partial snapshots or obsolete late refreshes become current. The SDK handles negotiation (`mode="auto"`, discovery or legacy initialize). Resource body TTL is separate: a zero or missing hint never caches the body. Scope any bounded cache to the connection, URI and generation, recheck read rights on every hit, and clear it on reconnect. The four list walks and caps follow archived §3.3 and the SDK's [cache contract](https://github.com/modelcontextprotocol/python-sdk/blob/77001c96f9507be0f4d009b83210a384a5e08bda/docs/client/caching.md).

5. **Serve the canonical address under the real caller's rights.** `/.vfs/mcp/<server>/{tools,resources,prompts}` are served directories outside the mount table. Include needed road directories for deeper grants. Apply 170-3's rules to canonical paths before names, metadata, matches, pages, errors or usage become visible. At list only, expose path and kind. At read, expose the manual or resource and admit the public `run` for a tool, including the parent line's policies, root masks and caller session. Share the 170-2 binder, including `--json` and stdin. Validate required fields, coercions and unknown top-level arguments before a wire call. Check fresh rights and exact server installation/tool digest at dispatch after any wait. A changed descriptor requires a fresh decision. Extend the serve startup inventory with the readable-to-everyone callable leaf paths, using one batch evaluation per server snapshot and the 170-3 threshold. A failed or partial rights proof admits nothing. No registration creates policy or an ordinary file.

Use the full tool path for execution and allow the caller to put the server's `tools` directory on its ordinary `PATH`. D64 names shipped programs and **host** tools. Leave MCP bare-name aliases out of the shared bin until that scope is enlarged. Thus two listings of `/.vfs/bin` alone issue zero remote list requests. T4 criterion 3's one-refresh pin applies at the MCP tools directory: two reads on one expired one-page snapshot make one `tools/list`, another line inside the floor makes zero. The sync facade, Python session, shell and served `cli` reach one call door.

6. **Render remote descriptions as data with a visible origin.** The tool manual starts with its exact name and a host-generated `runs on <server>` line, then the sanitized title, description, arguments, return schema, and inert icons and annotations. Remove control/format characters, escape peer strings as data, cap every description at `MANIFEST_DESCRIPTION_BUDGET=2000` Unicode characters including a visible ellipsis, and never retrieve icon URLs. Hash the full canonical descriptor (sorted compact UTF-8 JSON) separately for admission/recheck, including changes past the display cap. `stat.content_hash` is the digest of the actual rendered bytes and `size_bytes` their length. No source history is inferred. Ordinary readable `read`, `stat`, `ls`, `tree`, scoped `glob`, `grep` and help use the served image. The shell's `type` follows T1's path reporting. None sends `tools/call`. Host registration admits the server, and literal grants govern exposure. An in-flight approval pins the descriptor hash. This takes the memo's provenance, cap and change detection. Defer ranked search, permanent host pin lists and host-written “Use when” examples, for the same process-local catalogue and visibility reasons as 170-2 decision 14.

7. **Resolve a resource to the URI in the captured snapshot.** At `resources/<n>`, stat exposes the listing's MIME and supplied size, including an explicit zero. Leave unknown size absent on `Observation` (`src/vfs/models/entry.py:459`), without constructing a zero-sized `Entry`. Only an authorized body read of a concrete resource sends `resources/read`. One miss sends one request for the remembered URI, even if the index is concurrently refreshed. Translate each returned text/blob item as an embedded resource by the inbound adapter, keeping response order, URI metadata and the addressed resource path on each returned observation. A refresh can assign the same ordinal to a different URI. A literal grant applies to that slot. Avoid per-slot grants where the upstream order is unstable. A template lists its `uriTemplate`; body access is `vfs.unsupported` and never fetches. A prompt's readable manual lists its arguments; executing one is unsupported and never sends `prompts/get`. No URI in a reply initiates another request.

8. **Send each admitted tool request once and preserve its original reply.** Use SDK transport/negotiation and parameter-header mirroring, with the lower session's single `tools/call` request. Capture a bounded raw result on the transport stream by generation and JSON-RPC id, before typed union/output validation; clear the slot on every exit. The in-process fixture uses framed streams as well. Validate the negotiated envelope and each known block, preserve unknown blocks as opaque data, then apply the descriptor's output schema to `structuredContent` locally with in-document references only. The adapter receives the checked raw mapping. Do not recover arbitrary validation failures by treating the entire packet as valid. A peer's out-of-schema structured value does not discard its valid content. A malformed envelope gives the peer-protocol failure in decision 9. Require the spike to demonstrate the cap **before** unbounded stdio line or HTTP/SSE event accumulation. Use a bounded transport reader if the selected SDK transport exposes only an already buffered body.

Use the tighter of the remaining line deadline and `WALL_TIME_BUDGET` (`src/vfs/deadline.py:36`). Apply 170-2's input/output byte ceilings, 171-1's block/media ceilings and a declared `MCP_BLOCK_LIMIT=1024` for result items before constructing row lists. A wire frame over `MCP_FRAME_BYTES=TOOL_OUTPUT_BYTES` or too many items fails `vfs.budget_exhausted`, exit 137; an individual oversized media block within a valid frame follows the adapter's placeholder and warning. Close a transport if a discarded frame cannot be resynchronized. Do not use the SDK's higher-level retry loop. On `HEADER_MISMATCH`, invalidate the snapshot for independent rediscovery, fail the current invocation and never resend it. D11 withholds a general promise of idempotence (`context/standards/roadmap.md:1222`). Neither cancellation, a retryable transport kind nor an upstream annotation authorizes replay.

9. **Classify the boundary that failed.** Apply local authorization first. Reduce exception groups to their leaves before classification. External task cancellation propagates; a locally expired wall takes precedence over the resulting transport cancellation. A known transport leaf marks its generation broken. Return bounded, redacted detail naming the admitted path. Keep unclassified local programming faults distinct from peer failures.

| Outcome | Result and stage exit |
|---|---|
| Bad arguments, or peer JSON-RPC `-32602` | `vfs.invalid`, 2. Local refusal sends zero calls. |
| Absent or hidden name, removed tool, or `-32601` | `vfs.not_found`, 127. A listable tool below read is `vfs.permission_denied`, 126. |
| Valid foreign `isError: true` | Exit 1, text blocks in wire order on stderr, structured extra retained, zero rows, no minted kind. Native VFS envelopes retain the adapter's own failure facts. |
| Missing client capability (`-32021`), unsupported input form, or exhausted input rounds | `vfs.unsupported`, 126 at the capability gate. An actionable elicitation follows decision 10. |
| `-32000` connection closed, dead child, HTTP session loss or broken wire | `vfs.unavailable.backend`, 1. The next eligible independent request reconnects. |
| Other unrecognized remote RPC error or malformed reply | `vfs.unavailable.backend`, 1 with sanitized reason. Invalidate a connection only on loss of framing, session or transport. |
| Header mismatch | `vfs.conflict`, 1. Rediscover before another invocation. |
| Local wall expired | `vfs.timeout`, 124. Cancel this request only. Caller cancellation follows the shell's existing 130 path. |
| Successful reply with invalid/missing declared structured output | Keep valid content rows, drop the structured value and append one nonfatal `vfs.unavailable.backend` warning identifying upstream output validation. Exit 0. |

10. **Return elicitation to the caller through the landed job contract.** D9 calls for carrying the question without asking or blocking (`context/standards/roadmap.md:1220`). Before jobs land, decline elicitation at the capability gate (`vfs.unsupported`, 126) and install no interactive callback. If jobs land first, a supported answerable form becomes the job's `vfs.interrupted` result and a suspended shell exit of 75. Commit before returning, release the worker and keep no open connection or transaction on behalf of the question. Do not mint `vfs.pending`. A missing capability with no question remains 126. A system caller follows job decision 30 (`vfs.invalid`, 2).

For a modern input-required result, adapt each form to a strict, extra-forbidding Pydantic answer type using its named primitive properties, required keys and enumerations. Refuse unsupported schema keywords before creating a job. Enforce the job's message, schema and details limits. Retain its opaque `requestState`, original request keys, stable installation/digest, arguments and caller in the private job part. For several form requests, use one bounded answer object keyed by request key. Bind the private state to the original server, credential identity and negotiated revision. Exclude it from the preview, return payload, logs and manifest. On resume derive the correct peer input-response object for each saved key, authorize and claim via job decisions 16–24, then send one explicit continuation carrying the saved state and answers. A changed identity/schema, lost right, expired token or uncertain previously sent continuation cannot fall back to the initial call. Report conflict or the existing in-doubt job outcome without another send. Limit resumed rounds to the selected SDK's declared input-round ceiling, counted across resumes. An unresumable legacy callback, URL elicitation, state-only polling, sampling, roots and an input round without a demonstrably resumable state stay capability refusals. The job carries a question only if continuing it preserves the upstream request's effects; a blocked legacy handler cannot survive a process restart.

11. **Publish foreign block files with the run store's owner, commit and lifetime.** Pass the per-invocation base to 171-1 decision 11. Text, image/audio, embedded text/blob, link and unknown blocks use their original wire index; non-native structured-only input yields one compact JSON row. Retain the adapter's `links`, `structured` and `vfs.blocks` extras in the result. A native VFS result follows decision 10 of that adapter, including reattachment to its own observations. A peer-supplied path never chooses a file for publication. Only locally assigned decimal indices are store keys.

For a named logged invocation obtain its own H0 call id/claim before send. Calls inside the same line each get a distinct id, separate from the enclosing line's stdout/status id. Add a private discriminator to T2's run head, defaulting old heads to the line shape. A tool record with output uses a bounded descriptor per block in proposed `vfs_kernel_run_blocks(call_id, ordinal, source, mime_type, size_bytes, content_hash, page_count)`, primary key `(call_id, ordinal)`. Reuse `vfs_kernel_run_pages` with decimal `part` keys. Write descriptors and pages in the same H0 completion commit as the ready head. Charge all descriptors and body bytes to T2's owner retention and reclaim dependents in its sweep. Empty byte or text blocks have a descriptor with zero pages. A foreign tool error with no observations completes the claim without a block directory. Extend the kernel's private format at landing. Do not change the mount format or create postings, file entries or grants.

`/.vfs/run/<id>/<i>` is reported as a durable address only after commit. Join live, unexpired exact-owner heads before listing, paging, stat or body fetch. A different owner sees a missing file even with a root grant. Reopening a block consumes ordinary projection, including explicit byte fetching. Anonymous, system and logging-disabled calls receive their in-hand observations only, using the tool path as the temporary adapter base. A failed completion returns the captured output at the temporary base plus the classified store failure without publishing a run id. Retrying an uncertain commit only settles its claim. It never runs the tool again. This extends the two-file projection of 169-3 explicitly, preserving that draft's ownership and visibility rules.

## Cost

At the [reference deployment](../../AGENTS.md) there are 1,000 callers and 150,000 verb calls a day against ten million files. With one hot one-page server for eight hours, the default 30-second list floor admits at most 960 scheduled refreshes plus initial discovery, instead of 150,000 lists. For each fresh snapshot the bound is the sum of pages of advertised methods, at most four times `MCP_LIST_PAGE_BUDGET`. A cold connection also negotiates once. Warm tools are looked up by name and resource slots by index. Grant checks cost the existing evaluator's chunks of **distinct ancestor keys**, bounded by `membership_budget(profile, parameter_budget)`, including on SQLite's smaller bind floor. No catalogue listing scans the estate, opens a writer or adds index-pass work.

Keep at most `MCP_SERVER_LIMIT` owners and `MCP_IN_FLIGHT` workers per owner. Bound decoded frames, outstanding reply captures and body-cache bytes collectively per router by `TOOL_CATALOGUE_BYTES` in a separate charged pool. Reserve before accepting a frame/worker allocation, release on cancel or refusal, and evict least-recently-used bodies before admitting a new cache entry. A full pool refuses new work rather than waiting inside a read. Per tool call, validate and copy in linear time in admitted bytes and at most `MCP_BLOCK_LIMIT` items. Rights are proved outside network waits. A listing reads immutable snapshots. The topology lock covers publication only.

For a durable answer with B blocks and P body pages, add B descriptors and P pages. If every call yielded five blocks, that would be 750,000 descriptor writes per day before retention, with no corpus or embedding work. Bound the heads by T2's per-owner count/bytes/lifetime; descriptor batches use the least of the store's bind limit divided by seven columns and its row budget, and page batches use T2's smaller bind, row and statement-byte bounds. Zero-body stat fetches zero pages. Read one authorized body in one statement snapshot. Claim and publication each hold a writer only for a commit, outside the remote call. An independent disposable Postgres SQL oracle with a retired head, five live descriptors and two binary pages returned five descriptors for their owner, zero for another and ordered bytes `ff007f`. This was a projection oracle, not T4 storage.

Place the client, catalogue and owner under `src/vfs/mcp/client.py`, `catalogue.py` and `supervisor.py` respectively. ## Choices to confirm

1. **MCP tools on the default PATH.** Take canonical server paths and opt-in PATH directories. D64 names host tools, and adding a default alias later can preserve every server address. A shared bare alias needs a separate collision and rights ruling.
2. **Catalogue text, caps and resource slots.** Take the host-admitted, rights-filtered catalogue, a digest recheck, bounded plain-text manuals and scoped grep. Take snapshot ordinals as in archived §3.2, with grants explicitly attached to slots. Prefer these reversible additions over mandatory persistent approval, a new ranking index or a claim that an ordinal denotes a permanent URI. Start the named page, description, registration, concurrency, frame, block and backoff budgets in decisions 3–8 at their stated defaults, adjustable after the counted studies.
3. **Call output storage.** Take separate tool-call ids and additive numbered projections in the root store, charged to the same owner window. Sharing one line id would collide on block zero when two tool stages run. The durable publication build waits for H0 and 169-3 to supply the claim and atomic completion seam; a substitute claim after a possible external effect cannot be reconciled safely.
4. **Upstream replay and protocol compatibility.** Take a single send, bounded raw-reply capture and explicit modern-state continuation. Leave legacy forms without persisted continuation at 126. The wire integration waits for the first spike to demonstrate framed unknown-block preservation, bounded transport input, and zero automatic resends on the chosen SDK release. The interrupting path waits for the job contract and a proven effect-preserving continuation; repeating the original tool call has no reversible outcome.
