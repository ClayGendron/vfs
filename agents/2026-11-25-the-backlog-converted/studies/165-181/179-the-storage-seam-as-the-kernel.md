# Study: The storage seam as the kernel, with declared capabilities, the atomic unit as a trait, and the crash-point and access-path families

## Verdict

live-0.1.0, split across two gates. Nothing the spec builds is in the tree except one bullet of §4.1 (the two rows-in-hand filters lifted out of `base.py` into `src/vfs/chain.py`), which the archived router-keeps-routing landing did in a different shape. The roadmap places the spec as story K7 at gate f, and places its slice D (the conformance battery split) under story K9 at gate b; the protocol regroup of slice A renames and removes public storage protocols, which K9 freezes, so it can land only before the freeze (INFERRED, below).

The design stands in substance. Its names are stale throughout (`glean`, `graph`, `reindex`, 21 seams, 22 tables, 220 and 75 tests, every line range), three acceptance lines of roadmap K7 disagree with the spec's own shape, and two of its slices (the access-path tables and the revalidation fold) are not named by any roadmap acceptance line.

Precedent: `DatabaseStorage.first_touch` and `install_extensions` are unrouted backend methods (READ, `backend.py:1091,1098`); the roadmap defers an OpenTelemetry exporter and per-call counters on `Result` to 0.2 and puts operator counts in the action log H0 (READ, `roadmap.md` §15 rows "A per-call statement and timing counter" and "An OpenTelemetry exporter").

The groups leave this spec for 181/K9.
4. §2.4 and K7 criterion 4: the atomic unit as one backend trait (`call`/`mount`/`row`) plus a per-method `METHOD_ATOMICITY` table, versus the roadmap's "`traits()` declares `whole_batch`/`resumable` per verb". Lean: the spec's split. HOLDS-AMENDED. Precedent: a trait is one value per key per backend (READ, `protocol.py:78-89`), so a per-verb model cannot be a trait value; amended text: "K7 criterion 4 is met by `METHOD_ATOMICITY` and its drift test; `traits()` carries `atomic_unit` alone."
5. §3.3 and K7 criterion 3: the field's members `{dialect, sqlstate, code, name}` versus the roadmap's `{sqlstate, code, driver}`. Lean: the spec's. HOLDS-AMENDED. Precedent: the tree already reads exactly these driver attributes (READ, `dialects.py:1013-1030`), and SQLite's `sqlite_errorname` and Oracle's `full_code` are the drivers' own names (python `sqlite3` and python-oracledb documentation); amended text: K7's `driver` reads as `dialect`, the members present only when the driver carries them.
6. K7 criterion 5's derived `rmdir`. FAILS against the tree: there is no `rmdir` op (READ, `src/vfs/ops.py:36-62`); `delete` takes `cascade` (READ, `src/vfs/params.py:185`), and the kernel memo names `rmdir` a facet's spelling of `delete` on a directory (READ, `context/research/2026-10-23-a-filesystem-shaped-kernel-for-vfs-prior-art-and-the-recommendation.md:66,84`). The derived set is the spec's: `tree`, `copy`, `glob`, `grep`, `edit`.
7. §2.1: a declaration with one possible value is a feature, not a trait (178's `read_range: "engine"` becomes a feature). HOLDS. Precedent: every live trait has at least two values (READ, `protocol.py:83-90`); `capabilities()` already answers presence as a set (`backend.py:242-252`).

Precedent: a precondition checked outside the write's transaction is check-then-use, which POSIX `open(O_CREAT|O_EXCL)` exists to make atomic (POSIX `open()`); 178 already designs the router slice for a missing range (READ, spec 178 §6 as cited by spec 179:120).

Precedent: the probed settings are each engine's documented commit-durability switch (PostgreSQL `synchronous_commit`, MariaDB `innodb_flush_log_at_trx_commit`, SQL Server `delayed_durability`, Oracle `COMMIT_WAIT`); reading an engine fact once at first touch is the posture AGENTS.md states for engine settings ("refused at first touch or flagged").
