## Units proposed

1. Slug `a caller's rung at many catalogue paths is one chunked statement per budget slice`. Title: `SupportsGrants.rungs_at(paths, *, authority)` returns the caller's rung at each path from posture rows and spans on its chain, in `ceil(len(paths) / membership_budget)` statements on every engine leg, equal to a Python oracle. Gate b (I3a). Depends on K9 (READ, `roadmap.md:398`). Rewrite depth: amend (the content of §5.1 stands; the oracle, the engine legs and the K9 dependency are new facts).
2. Slug `a registered host function is a file under the tools view and a command by name`. Title: A host function registered once appears at `/.vfs/tools/<name>` and in `/.vfs/bin`, reading it never runs it, and typing its name runs it through one gated door with flags mapped from its schema. Gate b (T3). Depends on T1, T2, F3, F4 (the runner and `/.vfs/bin`), unit 1, K9 (`run` gone). Rewrite depth: amend (§1, §2, §5's door and §6 stand; ADR citations, constant names and the `Fs` handle must be restated in words; criterion 12 moves to K9).
3. Slug `a catalogue posture decides who may see and who may call a tool`. Title: `grant` and `posture` at a catalogue path are lawful, the mutating verbs there are `vfs.invalid`, and with posture `list` a caller sees every tool's name and calling one is exit 126 with zero invocations. Gate b (I3b). Depends on unit 1, unit 2, T1. Rewrite depth: amend. INFERRED that this unit may fold into unit 2 at conversion if T1 lands the catalogue path grammar; the roadmap keeps it apart.
4. Slug `a connected MCP server is a directory of tools resources and prompts under the mcp view`. Title: A server connected with `add_mcp` appears under `/.vfs/mcp/<name>/`, its tool calls come back as rows by the inbound block table, each failure around a call maps to its kind and exit, and one supervisor task owns each connection. Gate b (T4). Depends on unit 3, M1's `from_call_tool_result` (or lands it), H1 (the interrupt rule), and the three study tasks run first. Rewrite depth: amend (§3, §4, §7 stand; SDK facts must be re-verified against the current python-sdk and the schemas M1 vendors).
5. Slug `a mounted server is called with the credential the host resolves for the caller`. Title: `add_mcp(..., credentials=)` takes a static credential or a `CredentialResolver`, opens one connection per distinct principal, and never lets the credential reach a row, a result, a log or a child's environment. Gate f (I4). Depends on unit 4, I1, D16. Rewrite depth: rewrite (the roadmap says the design changed from §3.1's one credential per server; the roadmap calls for a new spec, so this unit may instead be written fresh and only cite this one).
