## Security

The method was `.claude/skills/security-audit/SKILL.md` in guidance mode, with no run folder. Blocks read in `ATTACK-CLASSES.md`: Access control, Cryptography and secrets, Business logic, Feature abuse and data leakage, and Obvious things. The diff touches no MCP tool input.

Boundary 1, data isolation. A caller who may list a row but not read it supplies a read verb. The control is the bare row, and the sink is the vid on the returned row. Record: `rejected`. Bare rows carry no vid and mint nothing: EXECUTED, by `VidContract::test_a_bare_row_carries_no_vid` and the 0 mints of `TestVidCost::test_a_listing_mints_once_for_each_row`.

Boundary 2, refusal data. A caller supplies a create-only write or a version-guarded write. The control is the rung check before the plan settles, and the sink is the `data` of `exists` and `conflict`, which now carries the vid. Record: `rejected`. `exists` is reached at `add` or above and `conflict` at the verb's own rungs. Both rank above `read` (`none < list < read < add < contribute < read_write`, `src/vfs/storage/grants.py:86`), so the caller may already read the row whose vid it is told. READ.

Boundary 3, cryptography. The vid is a keyed blake2b whose key is the mount identity. That identity is a ULID, readable by code that holds the storage object through `DatabaseStorage.mount_identity`, a property that predates this range. Record: `rejected`. A vid is a validator compared for equality and never an authenticator: it grants nothing, and rights are judged on every call. The entry id it hashes never leaves the storage, so knowing the key does not let a caller take a vid apart or name an entry it cannot read. READ, against decision 2's reason.

Boundary 4, resource exhaustion. A caller supplies a 10,000-row listing. The sink is one mint per row. Record: `rejected`. It is bounded by the page, and no statement is added: EXECUTED, by the two `TestVidCost` tests.

Injection: none. The only new SQL is a `type_coerce` of a column under a constant label, with no text from a caller.
