folder) loaded into a real `DatabaseStorage` mount with the shipped
`bulk_insert` — labels computed from the world's posture rows — plus a

## Against the acceptance criteria

| criterion | result |
|---|---|
| ordinary caller compile under 1 ms | **met on the hit path** (0.41 ms, every call after the first); **not met on the miss path** (2.98 ms: the closure walk, the stamps, the rows and two resolves — paid once per caller, then only when a write names the caller) |
| compile under 20 KB | met: 2.1 KB of binds |
| `tree /` within 1.5× of the system actor | met: 1.16 cold, 1.49 warm (SQLite); 0.58 / 0.71 (Postgres) |
| `ls /home` within 1.5× | **not met**: 2.5× on SQLite, 2.5–4.8× on Postgres. The cost is the road probe: 100,000 hidden homes, one `EXISTS` seek of the `(everyone_level, path)` index each, chunked 1,000 candidates per statement. The system actor lists 100,100 rows in 0.72 s; the ordinary caller lists 101 names in 1.79 s, of which the probe is the whole |
| `glob /shared/*/*.md` within 1.5× | met: 0.79 / 1.01 (SQLite); 0.63 / 1.60 (Postgres, 20,000 rows at 135–244 ms, inside noise) |
| `admits` under 10 µs per row | met: 0.17–0.42 µs |
| one cached `Rights` under 100 KB | met: 55.6 KB by `weight()` (which counts every string per occurrence, so it overstates) |
| posture change on 1,000 rows under 100 ms | met warm (15 ms), **missed cold by 6 ms** (106 ms on the first call of the run; 68 ms on Postgres) |
| posture change on 1,000,000 rows under 30 s, no statement over `RELABEL_ROWS` | met: 2.29 s, 84 statements, no statement over 49,998 rows |
| a grant to one user invalidates one cached caller | met: 1 of 200; a group grant exactly its cached members; a posture change nobody |

Numbers next to slice B's run of the same world (2026-10-03, before
slices C, E and F): `tree /` ordinary went 4.5 s → 10.9 s, but the system
actor's went 5.8 s (the baseline's figure) → 9.4 s on the same day's
machine, so the gate's ratio is the honest measure and the predicate is
not the cost; the unscoped `tree /` is now the nine-branch statement
(slice F sends every piece branch live and trashed), which the
within-1.5× result absorbs. The compile went 4.3 ms → 2.98 ms on the
miss path and gained the 0.41 ms hit path.

## Rerun

    uv run --no-sync python bench100k.py --engine sqlite --n 100000 --big 200000 --cached 200
    uv run --no-sync python bench100k.py --engine postgres --n 10000 --big 50000 --cached 200
    uv run --no-sync python bench100k.py --engine sqlite --n 100000 --big 1000000 --only posture

`bench100k.py` lives in the slice's scratch; its JSON output per run is
beside it. The world, the loader and the measurements are the slice-B
bench's, plus: the hit path, `weight()`, the system actor on every verb,
`admits` over five row shapes, the largest `UPDATE` rowcount during the
relabel (an `after_cursor_execute` listener), and the invalidation
counts (200 callers cached by one `stat` each, `resolve` counted per
cache miss).
