## Premortem

The site is deployed as built, and it fails in three likely ways.

A reader follows an old link from another site. The host answers with `404.html`. With scripts on, the reader sees a header with no sections in it; with scripts off, or to a crawler that runs none, a white page with no title and no link. Nobody saw it before the deployment because no test opens that file. That is M1.

The docs check goes red on a pull request that changed one docstring, on a node about a button, and green on the re-run. After the third time the check is re-run by habit, and the day it is red for a real reason it is re-run too. That is M2.

The deployment spec is completed by someone who reads decisions 1 and 21 of this one, "no page names its own host" and "names no host", and plans a preview at another address; every page of the preview tells a search engine that its one address is `docs.vfs.dev`, and its sitemap lists 26 addresses on a host that does not answer yet. That is L1.
