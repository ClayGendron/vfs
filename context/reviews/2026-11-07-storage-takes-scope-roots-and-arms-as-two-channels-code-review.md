## Security

Method: `.claude/skills/security-audit/SKILL.md` in guidance mode; no run folder, no output directory, no findings file, no artifacts.

Boundaries the diff touches, each as the lower-trust principal, its input, the control and the sink:

- **Access control.** The anonymous caller (the router's default authority) supplies scope roots and arms. The control is `_scoped_refusals`, the posture gate. The sink is `glob_rows`, `grep_rows` and `glean_rows`, which return rows.
- **Data isolation.** The same caller sends roots under `/.vfs`. The control is the meta exclusion in `scope_root_arm` and the marked-only rule in the grep and glean gates. The sink is meta rows.
- **Resource handling.** The same caller sends trash roots. The controls are `admit_scope`'s per-side split and `trash_scope`. The sink is tombstoned rows.
- **Injection.** Root text and arm text reach the SQL builders. The control is bound parameters and escaped `LIKE` patterns. The sink is the engines.
- **Resource exhaustion.** The same caller sends a wide scope. The controls are the wall and the chunking. The sinks are the offload pool and the loop.

Blocks read in `ATTACK-CLASSES.md`: Access control; Injection; Resource and file handling; Business logic; Feature abuse and data leakage; Chained vulnerabilities and trust boundaries; Obvious things. The diff touches no MCP tool input, so `AI-AND-LLM.md` was not needed.

Records:

- `rejected`: an anonymous scope judged anywhere other than where composition judges. The posture gate is built for every anonymous call that carries a scope and for no other (`_scoped_gate`). Composition judges the same list, so the gate judges at the same places on both sides of the switch. It never adds `/` when the entry-wide channel is empty. Mutants M1, M2, M3 and M3b each turn a test red (EXECUTED). A gate that reaches its wall refuses the whole call before any read body runs, at each of its three stages (READ, EXECUTED in `TestPostureGate`).
- `rejected`: a meta row reached through a non-meta root. A scope root other than `/.vfs` or a path beneath it cannot cover a meta row, because the meta root is one top-level path. A pair's admission is marked only under a marked root. Glob's SQL lifts the meta exclusion only for a meta root (READ). M13 shows the grep pushdown pinned (EXECUTED).

Trash roots are judged at their stored paths in both shapes (READ). The 16 trash cases pass on every engine (EXECUTED).
